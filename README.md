# NetBakery

NetBakery is a GUI to generate MySQL Database first EntityFramework 6, EntityFramework Core, CakePHP2.x, CakePHP3.x and Cakephp4.x models.
For .NET it generates Models, Mappings, StoreCommands (with and without return layouts) and Context files.
For CakePHP it generates entities and tables.

The foreignkeys in the database are also applied to the generated models so it is easy to select data from linked models.

Here you can download the https://www.cmbsolutions/netbakery/netbakerysetup.latest.exe
